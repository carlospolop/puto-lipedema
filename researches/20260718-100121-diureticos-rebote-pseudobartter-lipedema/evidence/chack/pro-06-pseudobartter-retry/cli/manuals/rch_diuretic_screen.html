Urine Diuretic Screen - potassium depleting diuretics


Test Name
Urine Diuretic Screen - potassium depleting diuretics
Test Code
SASAB
Specimen Type

Urine

Minimum Volume
5 mL
Comments

The urine diuretic screening test includes screening for 12 of the most common potassium depleting diuretics (e.g. pyozides) and includes furosemide and mefurosemide. Confirmation of detected peak retention times is confirmed using diode array technique.

Additional information:

As of September 2017, Alfred Pathology offer urine diuretic screening using hgh-resolution time of flight mass spectrometry (UPLC/QTof). Refer to http://pathology.alfred.org.au/handbook
